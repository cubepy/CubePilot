# Contributing to CubePilot

CubePilot is free to use but **closed source** — the application's source
code is not published, and this repository contains no code. That means we
cannot accept pull requests that change the app.

It does not mean we don't need your help. Almost everything that makes
CubePilot better starts here.

## Report a bug

Open a [Bug report](https://github.com/cubepy/CubePilot/issues/new/choose).

A good report saves us a round trip:

- Search [existing issues](https://github.com/cubepy/CubePilot/issues?q=is%3Aissue)
  first, and add to that thread instead of opening a duplicate.
- Give the exact CubePilot version, your platform and your OS version.
- List the steps to reproduce, then what you expected and what happened.
- Attach logs or a screenshot when the problem is visual or intermittent.
- **Redact everything sensitive**: no private keys, passwords, passphrases,
  or real server hostnames and IPs. Replace them with `server.example.com`
  and `203.0.113.10`.

Found a security problem? Don't file an issue — follow
[SECURITY.md](SECURITY.md).

## Suggest a feature

Open a [Feature request](https://github.com/cubepy/CubePilot/issues/new/choose),
or start a thread in
[Discussions → Ideas](https://github.com/cubepy/CubePilot/discussions) if you
want to shape it with other users first.

Lead with the problem, not the solution. "I manage 40 servers across three
clients and can't tell them apart at a glance" tells us far more than "add
folders" — and often ends up as a better feature than the one originally
asked for.

Before you write it up, check [docs/roadmap.md](docs/roadmap.md); it may
already be planned.

## Improve the documentation

Everything under `docs/`, plus both READMEs, lives in this repository and
**does** accept pull requests. Typos, unclear steps, a troubleshooting entry
that solved your problem, a missing FAQ answer — all welcome.

## Translate

CubePilot ships in English and Persian. If you would like to see it in your
language, open a discussion. Translation is contributed through a string
file we can hand you — you never need access to the source.

## Help other users

Answering questions in [Discussions](https://github.com/cubepy/CubePilot/discussions)
is genuinely one of the most useful things you can do here.

## Spread the word

Star ⭐ the repository, and tell someone who is still juggling four terminal
windows. CubePilot has no marketing budget and does not want one.

## Code of conduct

Be decent to each other. Assume good faith, keep it technical, and skip the
personal remarks. Anything else gets moderated.
